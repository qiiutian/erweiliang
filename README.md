# iFEM 重构软件

面向逆有限元结构重构的桌面软件原型。当前版本支持二维梁“局部积分 ASP-iFEM”小变形重构、
二维/三维直线与解析圆弧混合路径、任意倾斜平面圆弧、公式参数曲线和单实体
B 样条/NURBS 建模、
测点布置、截面应变/应力后处理以及二维和三维结果显示。

## 启动

macOS 开发环境请使用项目脚本，避免误用缺少三维依赖的 Conda `base` 环境：

```bash
./run_in_venv.sh
```

启动后首先进入项目启动中心，可选择“新建项目”“打开项目”“示例工程”
或进入无测点的空白工作台。软件统一使用“石墨”主题：暖白表面、石墨文字与低饱和
蓝灰操作色，橙色仅保留测点语义。启动页和工作台不再提供主题切换入口；旧的本机主题
偏好自动兼容到统一外观，不修改项目文件。关闭启动中心会直接退出程序，不会在后台创建主工作台。

启动页采用留白构图和原生矢量动画：橙色应变贴片逐次显现，网格梁平滑重构形态，
虚线保留参考构形。银灰网格随窗口无损缩放，以约 12 秒的舒缓周期演示；变形为放大方法示意，
不是当前算法的真实计算结果。右下角可暂停/播放，选择会在本机记住；离开启动页、
打开项目库或应用失活时停止动画，不占用求解视口。自动遵循 macOS“减少动态”偏好，
也可通过 `IFEM_REDUCED_MOTION=1` 使用静态展示（`0` 显式启用动态）。
动画组件位于 `ifem/ui/start_animation.py`；旧 SVG 和栅格资源保留，但启动页不再加载。

也可以生成无需打开终端的本机 `.app` 启动器，并在桌面建立快捷入口：

```bash
./packaging/macos/build_launcher.sh --desktop
```

双击桌面的“iFEM 重构软件”即可启动，也可将其拖入 Dock。启动器仍调用当前源码，
后续修改程序后只需重新打开，无需重新构建；运行日志位于
`~/Library/Logs/iFEM Reconstruction/launcher.log`。

## 项目库

软件统一使用项目库管理 `.ifemproj` 文件，默认位置为：

```text
~/Documents/iFEM/Projects
```

- 新建项目时先输入项目名称，软件会预留对应的库内路径。
- `Ctrl+S` 保存到当前项目路径；“另存项目”只需输入新的项目名称。
- “打开项目”显示项目库列表、模型摘要和最近修改时间，不再打开系统文件选择器。
- 项目库窗口可直接在文件管理器中显示该目录，也可刷新和搜索项目；`Ctrl+F`
  聚焦搜索，Esc 先清除当前筛选。
- 开发或部署环境可通过 `IFEM_PROJECTS_DIR` 覆盖默认项目库目录。

旧 JSON 数据仍通过工作台中的数据交换入口导入，不作为项目库项目直接打开。

### 项目文件内容

当前 `.ifemproj` 是 `schema_version = 7` 的单个 UTF-8 JSON 文件，而不是压缩项目包。
文件会保存几何、材料与截面、测点、边界条件、分析工况、活动重构方法的稳定 ID、
插件版本、参数模式版本、不透明插件参数以及视图状态。方法切换和参数修改会写入活动
分析工况；插件缺失或版本不一致时，普通保存仍原样保留旧工况，只有用户明确采用或改绑
后才更新。保存通过同目录临时文件原子替换，并拒绝 NaN/Infinity，避免损坏已有项目。

工作台常用快捷操作：

- 左侧常驻导航切换模型、测点、约束、对比和高级工作区；有输入错误时显示数量，并可从状态按钮定位具体字段。
- `Ctrl+K` 搜索工作区、建模、运行、保存与显示命令；上下键选择，Enter 执行，Esc 关闭。当前不可用的命令会保留原因且不能执行。
- `Ctrl+Return` 或 `F5` 运行重构；输入有误时可激活“需检查”徽标定位首项。
- `Ctrl+1..3` 切换形态、应变和应力结果，`Alt+1..5` 切换五个输入页。
- `Ctrl+J` 收起/展开结果表格；输入区底部可收起测点布置。专注模式退出后保留面板开关选择，“更多 > 重置工作区布局”恢复默认分区，不修改项目。
- 结果表选择一行后按 `Ctrl+C`（macOS 为 `⌘C`），可复制为制表符分隔数据。

阅读与布局（`UI-019`）：从“更多 > 阅读与布局…”或命令搜索进入，可预览并选择
100% / 110% / 120% 字号，以及紧凑或舒适密度；点击“应用”后生效并记在本机。
“恢复阅读默认”先恢复预览，取消不会改变工作台。仍只有石墨主题，不增加风格选项。
工作台与建模器的窗口大小、分区比例，以及工作台的预览/结果面板开关在正常退出时记住；
取消退出不会保存这次布局，专注模式的临时隐藏不会影响下次启动。
“更多 > 重置工作区布局”和建模器“恢复布局”分别重置各自分区，保留字号、工程、草稿和撤销。
这些偏好不进入项目文件；结果图比例、物理单位及求解参数保持不变。

结果联动（`UI-020` 首个切片）：运行现有“局部积分 ASP-iFEM”后，选择节点、查询点、
实测对比或截面场的数据行，会同步定位二维图与三维结果模型，并在图下显示数值探针。
二维图单击、三维视图 `Ctrl+单击` 可反向定位数据行；普通三维拖拽仍用于旋转。
“定位数据行”会展开结果表并将键盘焦点移入该行，“清除”只取消探针，不修改工程。
截面表保留最多 240 条均匀抽样记录，拾取未列出的采样点会临时补入准确一行；
采样编号可能不连续，原始场交界处的左右单元即使坐标相同也保持独立。
切换原始/连续化场时清除截面探针并提示重新选择；其他视图切换保留当前选择。
输入变化后探针沿用上一次结果并明确标记“已过期”；新一轮成功结果清除旧选择，失败则恢复。
缺少 E 时应力仍显示“未提供”，不以零代替。此功能不选择或修改建模器中的实时工程对象，
也不代表空间曲线已有可求解算法。

结果诊断（2026-10-13）：新增“测点残差”，并列查看观测、重构和有符号残差（με），
汇总非加权 RMS 与最大绝对残差，选行可定位图中探针。这里使用原始解的测点点值：
`残差 = 重构应变 − 观测应变`，不是区间积分目标，也不是真实重构误差；不提供无依据的合格阈值。
缺失测点应变会明确阻止内置方法求解，显式 `0` 仍是合法观测。
“结果字段”按稳定 ID 浏览方法返回的全部字段、分量、参考位置和原始 SI 单位，按需绘制表格单元，
不丢弃稠密记录；支持多行复制原始精度。当前内置方法输出位移、转角、原始上下表面应变/应力与测点残差，
未提供 E 时省略应力。

通用结果工作台（2026-10-13）：符合 v1 契约的新插件可直接接入完整工程的校验/运行与结果显示，
无需返回旧二维求解对象。标准节点、位移和连接关系以真实 XYZ 或 XY/XZ/YZ 投影展示，
支持字段/分量切换、离散点与字段表双向定位，以及独立的“重构状态”节点表。
节点连线不代表曲梁精确几何；离散字段不自动插值为连续云图，无空间位置的记录仍可查表。
已有 ASP-iFEM 保留原连续截面场及 VTK 显示。通用接口通过四类状态的测试插件验证，
并不表示已实现另外三类重构算法；算法及项目格式边界见 `docs/RECONSTRUCTION_ALGORITHM_API.md`。

后台计算（`ANA-002`）：按钮、F5、命令搜索和空态入口均在后台校验/求解，显示算法实际阶段进度。
计算期间锁定输入、建模、项目切换/保存和比例设置，仍可查看旧结果和切换视角。
“取消计算”采用协作取消，当前不可中断的数值步骤结束后生效，不强杀线程；取消、失败或过期快照
都不覆盖已有结果。关闭时先确认取消并等待工作线程结束，再处理未保存输入。脚本测试仍可调用同步入口。
结果和任务状态仅存本次会话，不写入 v7 项目文件；项目格式与现有算法公式不变。

输入表格支持批量编辑（`UI-018`）：测点、位移约束和实测对比点可框选单元格，
复制/粘贴矩形数据、将一个值填入整个选区、向下填充或删除多行。测点表默认显示
位置与应变等简洁列，需要批量填写权重、截面 y 或积分区间时展开“全部字段”。
粘贴按当前可见列顺序处理，不接受表头或公式计算，也不会自动猜测积分区间。
新增行必须填写完整；字段不合法、选区尺寸不匹配或数据越界时整次拒绝，原表不变。
错误说明会自动滚动到可见位置；“更多”提供向下填充、全选和批量删除。

三张输入表共用最近 100 次操作的撤销记录，新增、修改、粘贴、填充和删除都可一次撤销。
表格获得焦点时使用系统复制/粘贴及撤销/重做快捷键；下方文本框仍使用自身的文字撤销。
保存不会清除表格历史，改变节点几何、载入项目/示例/JSON 或接受建模器修改时清除历史，
避免恢复到另一套几何。建模器自己的撤销栈与表格独立；列显示偏好和历史只在本次会话有效。
删除测点后保存，再撤销删除，可恢复原 ID、名称和通道信息；跨表撤销会说明改动了哪张表。

建模器右侧增加“对象列表”：按 `Ctrl+F` 搜索节点、梁段或测点的名称、编号与稳定 ID，
单击联动画布选中，双击或 Enter 打开对象属性。搜索框内按 Enter/向下键进入首个匹配对象；
删除和撤销继续使用原有模型命令栈。属性栏顶部常驻当前对象摘要，“编辑 / 列表”
可在属性和对象列表之间往返，保留搜索词与尚未应用的字段输入；列表单选与 Enter 编辑仍保持原语义。
面板布局按本机记忆，不写入项目文件。

建模器中“保存项目”与“应用到工作台”是两个独立操作：模型更改后通过关闭、取消或
选择模式下的 Esc 退出，会确认是否放弃未应用的更改，默认继续编辑。已保存到项目库的
文件不会因退出被删除或回退；撤销到进入时的模型不会多余提示。此保护目前覆盖已进入
模型的更改和属性字段草稿（`UI-017`）。

节点、梁段、测点以及截面/材料的未应用输入按稳定对象 ID 保留；切换对象、页签、
刷新或撤销不会覆盖草稿。“还原输入”只还原当前表单；底部草稿列表可定位、单项放弃
或统一应用。保存项目和应用到工作台前会统一校验所有草稿，出错时保留原始输入、
定位字段并滚动到可见位置；全部通过才一次提交，支持一次撤销。打开其他项目前提供
保存、放弃和取消；删除对象的草稿会保留，撤销删除可恢复，也可以显式放弃。
草稿仅在本次建模会话中保留，不写入项目格式，不提供程序崩溃或重启后的草稿恢复。

## 交互建模流程

1. 在启动中心选择“新建项目”，或进入工作台后点击顶部“交互建模”。
2. 先选择“二维建模”或“三维建模”，再选择直线段或解析圆弧段创建起始路径；也可点击“空间曲线…”以三个空间点创建任意倾斜平面圆弧，以 `x(t)、y(t)、z(t)` 创建公式参数曲线，或以控制点创建 B 样条/NURBS，并替换整条当前路径。
3. 参数方程页提供螺旋线、正弦曲线和抛物线模板，也可输入自定义公式、定义域和常量；表达式使用受限的 `ifem-math-v1` 数学语言，不执行 Python 代码。已保存的单实体参数曲线再次打开时会回填原定义。
4. 快速生成器可将直线和解析圆弧“追加到末端”；直段支持全局 `±X/±Y/±Z` 或沿末端切线续接。空间曲线当前保持为单个参数实体，公式曲线/NURBS 追加、控制点画布编辑和曲线混合路径仍属于后续 `MOD-012`。
5. 在 XY、XZ、YZ 投影视图中拖动节点，或在属性面板输入精确 `x/y/z` 坐标；二维模型固定在 XY 平面。
6. 使用“拆分梁段”插入节点，或使用“延伸梁段”绘制额外的直线路径段。
7. 可在平面视图添加上下表面测点，也可选择“三维表面测点”后直接在真实梁表面连续点击布点；悬停时预览弧长和环向角，按 `Esc` 退出。
8. 为整根梁选择统一的矩形、圆形、圆管、矩形管或工字形截面，填写尺寸和材料弹性模量，并保存为 `.ifemproj`。
9. 切换“三维预览”可查看截面沿直线、圆弧、公式参数曲线或 NURBS 路径的连续扫掠实体；测点红色贴片的长边与双向箭头共同表示测量轴，可分别设置环向位置和轴角。
10. 方法卡始终显示当前重构方法；只有存在其他已安装候选时才显示“切换方法”，插件恢复时则显示“替代方法”，单方法不会出现伪下拉框。软件只检查用户所选方法对当前模型是否适用、输入是否完整以及自由方程是否可解，不会静默替换选择。当前“局部积分 ASP-iFEM”可计算全局 X 轴二维直梁，其余模型可安全保存并等待相应插件。

测点位置、贴片和测量轴只在输入与建模视图中显示；二维和三维结果视图专注展示结构形态及应变/应力场，不叠加测点布置符号。

## 当前架构入口

- `main.py`：桌面程序入口和启动错误处理。
- `gui_qt.py`：当前 Qt 工作台，后续逐步拆分为独立工作区和控制器。
- `reconstruction.py`：现有二维梁“局部积分 ASP-iFEM”算法实现，架构重构期间保持数值公式不变。
- `ifem/domain`：与界面无关的算法协议和领域类型。
- `ifem/application`：算法调度和应用服务。
- `ifem/algorithms`：逆有限元算法插件及兼容适配器。
- `ifem/modeling`：可测试的梁节点、单元和测点编辑服务。
- `ifem/infrastructure`：项目文件和旧 JSON 兼容转换。
- `ifem/infrastructure/project_library.py`：固定项目库、命名校验和项目索引。
- `ifem/ui/project_library.py`：项目命名与项目库浏览界面。
- `ifem/ui/studio.py`：常驻工作区导航、命令搜索、模型对象列表和统一线性图标。
- `ifem/domain/result_fields.py`：物理字段定义、SI 校验与稳定 ID 空间映射。
- `ifem/ui/result_fields.py`：不依赖原生求解对象的通用字段浏览器。
- `ifem/visualization/generic_results.py`：真实分析节点连线与显式位置的标量点图层。
- `ifem/ui/generic_result_view.py`：通用结果的字段/分量选择、三维与投影视图。
- `ifem/ui/generic_workbench_results.py`：通用结果图表联动、状态表与工作台模式管理。
- `ifem/ui/analysis_job.py`：输入快照、后台任务、阶段进度和协作取消。
- `ifem/modeling/path_editor.py`：算法无关的空间梁路径、节点、单元和测点编辑服务。
- `ifem/ui/modeler.py`：直梁、曲梁和空间折线梁交互建模工作区。
- `ifem/ui/modeler_3d.py`：PyVistaQt/VTK 三维几何预览与拾取。
- `visualization_data.py`：结构模型与结果帧的可视化中间层。
- `visualization_3d.py`：PyVistaQt/VTK 三维结果视图，仅显示结构与结果场。
- `docs/RECONSTRUCTION_ALGORITHM_API.md`：二维/三维、小/大变形重构插件的统一接入契约。
