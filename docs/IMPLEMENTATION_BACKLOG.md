## 已完成纵向切片：ANA-001

目标：完成自适应分析方案的可靠性收尾，使后续新增二维曲梁、三维梁和
大变形算法时只需注册插件，不需要修改主窗口算法分支。

实施子项：

1. `DONE`：单算法自动选择并隐藏冗余选择器；多个兼容插件出现时自动开放切换。
2. `DONE`：根据插件 `parameter_schema()` 生成参数控件，参数进入插件上下文并写入活动分析工况。
3. `DONE`：项目 v6 保存算法与参数模式版本；插件缺失、版本变化和参数模式变化均保留原工况，只有明确接受或改绑后才更新。
4. `DONE`：模型、显示、测点、约束和动态参数使用稳定 JSON Pointer 字段；状态入口可直接聚焦对应控件或表格单元。
5. `DONE`：兼容测试插件无需修改 Qt 主窗口即可自动出现和切换，旧二维数值基线不变。

本切片不包含：真实新算法公式、实时数据接入、样条曲梁、分段截面和 CAD 导入。

完成定义：单算法无冗余操作，多算法可自动列出、选择、配置、保存和运行；
插件缺失可恢复，错误可定位到字段，旧二维重构回归结果不变。

验证结果：缺失插件打开/保存、显式改绑、版本与参数模式确认、旧项目无默认值回写、
动态参数服务校验、异常切换回滚和字段焦点均有自动化覆盖；完整测试集为 164 项。

## 开发规则

1. 每次只推进一个可验收的纵向切片，禁止同时重写界面、算法和文件格式。
2. 算法公式改动和软件架构改动必须分开提交。
3. 所有新算法先通过插件契约测试，再接入界面。
4. 所有几何和测点修改必须可撤销，并通过项目保存/恢复测试。
5. 每个里程碑结束时更新本文件状态和下一里程碑范围。
