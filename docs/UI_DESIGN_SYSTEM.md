# iFEM Qt 界面设计系统

## 1. 设计定位

本软件面向结构工程师与科研人员，是需要长时间使用的数据密集型桌面计算工作台。
界面采用白色、克制、清晰的专业语言，默认使用“云瓷蓝”而不再使用大面积灰绿，
优先保证模型输入、测点布置、结果比较和实时监测扩展时的信息效率，而不是追求
装饰性效果。

本轮参数基线：`DESIGN_VARIANCE=4`、`MOTION_INTENSITY=2`、`VISUAL_DENSITY=8`。
UI/UX Pro Max 用于数据密集型布局、可访问性和状态设计；Taste Skill 原本不以桌面
工程工作台为主要适用范围，因此只采用其审计、令牌化和预检原则，不照搬网页模板。

## 2. 视觉令牌

默认“云瓷蓝”令牌如下：

| 用途 | 值 | 使用规则 |
|---|---|---|
| 应用背景 | `#F3F6F8` | 工作台底层和区域分隔 |
| 主表面 | `#FFFFFF` | 表单、视口、结果表格 |
| 次级表面 | `#EEF3F6` | 工具条、摘要轨道、只读区域 |
| 主色 | `#315D7A` | 主按钮、选中态、键盘焦点 |
| 主色悬停 | `#274D66` | 可操作控件悬停 |
| 主色浅底 | `#E5EFF5` | 轻量选中提示和摘要强调 |
| 主文本 | `#26343E` | 标题和关键数据 |
| 次文本 | `#53636E` | 标签与说明 |
| 弱文本 | `#667680` | 辅助信息；白底对比度不低于 4.5:1 |
| 边框 | `#D8E1E6` | 面板和控件边界 |
| 测点语义 | `#D76547` | 仅用于输入/建模视图中的测点 |
| 危险语义 | `#A34D46` | 删除、错误和破坏性操作 |

内置浅色风格包括“云瓷蓝”“月白青”和“暖砂岩”。三者只替换语义令牌，控件尺寸、
状态含义、科学色图和项目数据完全一致；新安装默认选择第一项“云瓷蓝”。用户选择通过
Qt `QSettings` 的 `appearance/theme` 保存，不进入项目 JSON，也不影响项目跨机器打开。

应变和应力色图属于科学数据编码，不受单一 UI 主色限制。红色测点也属于领域语义，
不能用作普通按钮强调色，避免与结果场和危险操作混淆。

## 3. 字体与层级

- 界面字体依次使用 `Avenir Next`、`PingFang SC`、`Noto Sans CJK SC`。
- 标题、标签和数据统一使用无衬线字体，不混用宋体或装饰性字体。
- JSON、标识符和需要纵向比较的高密度数值可以使用 `Menlo` 等等宽字体。
- 主标题、区域标题、字段标签、辅助说明必须至少形成三级字重或字号差异。

## 4. 几何与密度

- 顶层工作区圆角为 `10-12 px`，普通控件圆角为 `6-7 px`，状态徽标圆角为 `12 px`。
- 输入区与结果区默认宽度约为 `1:2`，结果视口保持页面视觉中心。
- 使用边距、分隔线和背景层级组织内容，避免每一层都套用带边框卡片。
- 工具栏保持单行；窗口缩小时优先压缩说明文字，不允许主要操作按钮换行或遮挡。
- 主工作台最小验证尺寸为 `1180×760`；建模器最小验证尺寸为 `1040×680`，
  标准审查尺寸为 `1500×900`。

## 5. 交互规则

- 主操作使用当前主题的实心 `primary` 色，次操作使用白底描边；删除等危险操作
  单独使用危险语义，不硬编码某一套主题的绿色或蓝色。
- 所有可操作控件必须具有悬停、按下、禁用和键盘焦点状态。
- 启动中心可直接选择风格；工作台使用“更多 > 界面风格…”或 `Ctrl+,` 再次修改。
- 工作台风格对话框实时预览，确认后持久化，取消时恢复进入对话框前的风格。
- `Ctrl+M` 打开交互建模器，`Ctrl+Return` 或 `F5` 运行重构；`Ctrl+1..3`
  切换形态、应变、应力，`Alt+1..5` 切换输入页；后续快捷键不得覆盖系统常用组合。
- `Ctrl+S` 保存当前项目，`Ctrl+Shift+S` 另存项目；新建、打开、载入示例、JSON 替换和任何窗口关闭路径遇到未保存修改时必须提供保存、放弃、取消三种选择。
- 输入校验采用原位反馈：字段错误使用错误边框，页签显示错误数量，运行前聚焦首个问题；录入过程中不得用模态错误框打断。
- 输入就绪徽标必须可以通过鼠标、Enter 或 Space 激活：有错误时定位首个问题，
  无错误时运行分析；空结果视口必须提供同一条可恢复路径，不能只显示说明文字。
- 校验提示不得覆盖控件原有悬停说明；字段恢复有效后必须同时清除错误样式和旧错误文本。
- 输入变化后可以保留上一轮结果用于对照，但图、上下文条和结果区必须同时显示
  “结果已过期”，重新运行成功后才清除，避免将旧结果误当作当前结果。
- 计算和后处理必须以一次完整提交更新结果；失败时恢复上一轮有效结果并标记过期，
  错误对话框出现前必须退出 busy、恢复按钮和光标，任何校验刷新都不得重新启用运行入口。
- 科学结果表默认只读，数值右对齐并使用等宽字体；选中一行后可用平台标准复制
  快捷键（Windows/Linux 为 `Ctrl+C`，macOS 为 `⌘C`）复制为 TSV，便于进入表格、
  论文或工程报告。
- 专注模式只隐藏输入区和结果表格，退出后恢复原有可见状态，不改变模型、结果或分割器比例。
- 动画只用于必要的状态过渡，计算过程不使用持续装饰动画，以保证实时显示性能。
- 测点位置、贴片和测量轴只在输入与建模环境显示；结果视图专注结构形状和场数据。

## 6. 后续扩展原则

- 新算法参数面板复用现有表单令牌，不新增算法专属主题色。
- 实时监测使用同一工作台结构，在结果区增加时间轴、质量状态和告警层，不重新堆叠页面。
- 三维曲梁、壳和实体结果继续由 VTK 视口承载，Qt 负责工具、属性和状态，不重复绘制三维场。
- 嵌入式 PyVistaQt 视口关闭默认后台自动渲染，由 Qt 主线程按数据变化主动刷新；父窗口退出前必须停止定时器、断开渲染信号并显式关闭 VTK 交互器。
- 每次界面迭代至少检查标准尺寸、最小尺寸、键盘焦点、长中文标签和无三维后端降级状态。
- 算法公式、领域模型和数据协议的变化必须与纯视觉调整分开评审和测试。

## 7. 应用外壳规范

- 程序启动时先显示功能型启动中心，不使用只能等待的计时闪屏；主窗口仅在用户选择新建、打开、示例或空白工作台后创建。
- 启动中心只提供真实可用入口，不伪造最近项目；最近项目列表必须等待全局项目历史持久化完成后再增加。
- 启动中心复用工作台的白色表面、当前主题主操作和橙红测点语义，代码绘制的结构示意不得引入 VTK 或 Matplotlib 启动成本。
- 顶部工具区按意图分组：载入与数据交换属于次级命令，交互建模属于重要次操作，运行计算是页面唯一实心主操作。
- 建模器中的“保存项目”只写入项目库并保持窗口打开；“应用到工作台”只把当前
  模型交回分析工作台；会替换既有几何的生成动作必须明确写为“替换当前路径”。
- 工作区标题使用细窄主色强调线建立左右层级，不依赖大面积色块或额外卡片。
- 分析摘要只轻量强调用户选择的重构方法，其余模型、测点和材料指标保持同一阅读层级。
- 结果工具栏只负责切换；当前空间、物理场、连续化方式和材料参数放入独立上下文条，不能覆盖二维图或三维视口。
- 状态栏左侧显示即时操作结果，右侧保留单位制、计算位置、数据连接和后台任务等持久状态。
- 项目库支持 `Ctrl+F` 搜索；Esc 在有搜索词时先清除筛选。空库、无匹配和损坏项目
  必须给出不同且可恢复的说明，错误原因不能只藏在鼠标悬停中。
- Qt 原生图标只有在目标平台风格统一时才使用；若不同平台出现彩色、拟物或年代感不一致的资源，优先保留清晰文字按钮。
