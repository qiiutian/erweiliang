# iFEM Qt 界面设计系统

## 1. 设计定位

本软件面向结构工程师与科研人员，是需要长时间使用的数据密集型桌面计算工作台。
界面统一使用“石墨”主题：暖白内容面板、石墨导航与文本，以及低饱和蓝灰操作强调，
优先保证模型输入、测点布置、结果比较和实时监测扩展时的信息效率，而不是追求
装饰性效果。

本轮参数基线：`DESIGN_VARIANCE=4`、`MOTION_INTENSITY=2`、`VISUAL_DENSITY=8`。
UI/UX Pro Max 用于数据密集型布局、可访问性和状态设计；Taste Skill 原本不以桌面
工程工作台为主要适用范围，因此只采用其审计、令牌化和预检原则，不照搬网页模板。

## 2. 视觉令牌

唯一“石墨”主题（`graphite`）令牌如下：

| 用途 | 值 | 使用规则 |
|---|---|---|
| 应用背景 | `#F2F3F1` | 工作台底层和区域分隔 |
| 主表面 | `#FDFDFC` | 表单、视口、结果表格 |
| 次级表面 | `#ECEFEB` | 工具条、摘要轨道、只读区域 |
| 主色 | `#48616F` | 主按钮与选中态；焦点使用 `#587583` |
| 主色悬停 | `#3C535F` | 可操作控件悬停 |
| 主色浅底 | `#E8EDEF` | 轻量选中提示和摘要强调 |
| 主文本 | `#292E31` | 正文和关键数据；标题使用 `#23282B` |
| 次文本 | `#515B60` | 标签与说明 |
| 弱文本 | `#60696E` | 辅助信息；浅色表面对比度不低于 4.5:1 |
| 边框 | `#DBDEDC` | 面板边界；输入轮廓使用 `#BFC7C6` |
| 深色导航 | `#252A2D` | 工作区导航和建模器标题区；浅色文字 `#F0F2EF` |
| 测点语义 | `#B96D50` | 仅用于输入/建模视图中的测点 |
| 危险语义 | `#974D44` | 删除、错误和破坏性操作 |

按用户确认仅维护一个主题，不增加明暗或多风格选择器。历史 `porcelain_blue`、`mist_sage`、
`warm_stone` 和未知标识统一解析为 `graphite`，不需迁移项目。兼容层读取旧 `QSettings`
时不强制回写；显式保存使用统一标识。颜色令牌继续供 Qt、二维绘图及三维视口共用。

应变和应力色图属于科学数据编码，不受单一 UI 主色限制。红色测点也属于领域语义，
不能用作普通按钮强调色，避免与结果场和危险操作混淆。

## 3. 字体与层级

- 界面字体依次使用 `Avenir Next`、`PingFang SC`、`Noto Sans CJK SC`。
- 标题、标签和数据统一使用无衬线字体，不混用宋体或装饰性字体。
- JSON、标识符和需要纵向比较的高密度数值可以使用 `Menlo` 等等宽字体。
- 主标题、区域标题、字段标签、辅助说明必须至少形成三级字重或字号差异。

## 4. 几何与密度

- 顶层工作区圆角为 `10-12 px`，普通控件圆角为 `6-7 px`，状态徽标圆角为 `12 px`。
- 输入区与结果区默认宽度约为 `1:2`，结果视口保持页面视觉中心。
- 左侧常驻导航宽 `70 px`，输入检查器与结果区之间可拖动分隔。输入区预览和结果表格可独立收起；工作台与建模器的窗口尺寸/分区比例分别在本机记忆，不新增停靠窗口。
- 使用边距、分隔线和背景层级组织内容，避免每一层都套用带边框卡片。
- 工具栏保持单行；窗口缩小时优先压缩说明文字，不允许主要操作按钮换行或遮挡。
- 项目名称和摘要按可用宽度省略显示，同时保留完整文本、悬停提示和可访问名称；不得通过裁切固定像素隐藏内容。
- 图标使用同一套线性绘图；数值输入和选择控件统一轮廓与箭头，避免混入平台原生三维浮雕控件。
- 主工作台最小验证尺寸为 `1180×760`；建模器最小验证尺寸为 `1040×680`，
  标准审查尺寸为 `1500×900`。

## 5. 交互规则

- 主操作使用当前主题的实心 `primary` 色，次操作使用白底描边；删除等危险操作
  单独使用危险语义，不硬编码某一套主题的绿色或蓝色。
- 所有可操作控件必须具有悬停、按下、禁用和键盘焦点状态。
- 不再显示启动页主题选择器、工作台侧栏外观按钮、更多菜单换肤项、命令搜索换肤项或 `Ctrl+,`。不保留只有一个选项的空设置窗口；绘图参数和布局重置不受影响。
- `Ctrl+M` 打开交互建模器，`Ctrl+Return` 或 `F5` 运行重构；`Ctrl+1..3`
  切换形态、应变、应力，`Alt+1..5` 切换输入页；后续快捷键不得覆盖系统常用组合。
- `Ctrl+K` 打开命令搜索：支持多词筛选、上下键选择、Enter 执行与 Esc 退出。命令必须调用真实现有动作；禁用项标明不可用，不得通过搜索入口绕过运行校验。
- 常驻导航显示当前输入页和错误数量，与原有字段校验、快捷导航保持同步；在专注模式下定位输入页或错误时自动恢复输入面板。
- `Ctrl+J` 切换结果表格；测点布置可独立展开/收起。“重置工作区布局”只恢复面板可见性和分区比例，不改变项目或分析结果。
- “更多 > 阅读与布局…”及命令搜索提供真实的字号/密度设置，不恢复换肤入口或 `Ctrl+,`。支持 100/110/120% 与紧凑/舒适，预览只在对话框内变化，确认应用才更新工作台并记在本机；取消和暂存的默认选项不能影响工作区。
- 字号始终从原始样式派生，不累计缩放；舒适模式增加控件垂直空间和表格行高，不压缩或重写数值。颜色仍使用石墨令牌，科学图比例/单位及启动页方法动画不随阅读设置改变。
- 布局只存窗口尺寸、分隔比例和辅助面板开关，不保存屏幕位置、最大化/专注状态、选中实体、搜索词、草稿或项目数据。损坏/未知版本安全回退，尺寸受当前屏幕和既有最小尺寸约束。
- 有效退出后才记录布局；取消、草稿失败或保存失败不落盘。临时隐藏不得覆盖正常比例，关闭后的窗口不能重启恢复回调；旧建模器资源清理不得覆盖较新实例保存的布局。
- 阅读默认与布局重置相互独立；主窗口只重置工作台，建模器只重置自身。重置保留项目、结果、未完成字段与撤销历史，程序载入工程不清空本机偏好。
- 建模器上下文条显示当前对象及短 ID，完整信息保留悬停/可访问说明。“编辑 / 列表”只导航，不重新选取或重填表单；保持列表单击仍留列表、Enter 才进入属性的键盘契约。
- 建模器 `Ctrl+F` 聚焦对象搜索，节点、梁段和测点按稳定 ID 联动。单击只选中并保留列表，双击或 Enter 打开属性；搜索框 Enter/向下键进入首个匹配项，空结果给出恢复提示，回车不得冒泡触发默认文件按钮。
- `Ctrl+S` 保存当前项目，`Ctrl+Shift+S` 另存项目；新建、打开、载入示例、JSON 替换和任何窗口关闭路径遇到未保存修改时必须提供保存、放弃、取消三种选择。
- 输入校验采用原位反馈：字段错误使用错误边框，页签显示错误数量，运行前聚焦首个问题；录入过程中不得用模态错误框打断。
- 输入就绪徽标必须可以通过鼠标、Enter 或 Space 激活：有错误时定位首个问题，
  无错误时运行分析；空结果视口必须提供同一条可恢复路径，不能只显示说明文字。
- 校验提示不得覆盖控件原有悬停说明；字段恢复有效后必须同时清除错误样式和旧错误文本。
- 输入变化后可以保留上一轮结果用于对照，但图、上下文条和结果区必须同时显示
  “结果已过期”，重新运行成功后才清除，避免将旧结果误当作当前结果。
- 重构方法卡是活动方法的唯一状态来源；没有其他候选时隐藏切换控件，正常状态使用
  “切换方法”，插件恢复状态使用“替代方法”。候选文本必须同时给出可求解、待校验或
  不可求解状态及原因，不以颜色作为唯一信息。切换控件不响应滚轮切换，保留键盘显式
  选择；未确认替代前不得改写项目工况。
- 计算和后处理必须以一次完整提交更新结果；失败时恢复上一轮有效结果并标记过期，
  错误对话框出现前必须退出 busy、恢复按钮和光标，任何校验刷新都不得重新启用运行入口。
- 科学结果表默认只读，数值右对齐并使用等宽字体；选中一行后可用平台标准复制
  快捷键（Windows/Linux 为 `Ctrl+C`，macOS 为 `⌘C`）复制为 TSV，便于进入表格、
  论文或工程报告。
- 结果选择只作用于已求解快照，绝不反向写入建模对象或输入表。二维单击、三维 Ctrl+单击、表格鼠标/键盘选行共享一个数值探针；切换视图不抢焦点，“定位数据行”才主动展开表格并聚焦。
- 三维拾取按实际网格携带的节点/采样索引映射；原始模型、装饰和高亮不可作为结果拾取目标，普通旋转/缩放不改变选择。高亮不改变相机、坐标范围或科学色图。
- 截面场按快照、表示方式、单元及采样身份关联；原始场同坐标两侧不得合并，切换连续化时明确清除截面选择。表格抽样必须保留真实样本索引，漏列的拾取样本补入准确行，不就近猜测数值。
- 探针使用轮廓/站位线和文本共同表达选中，完整数值、工程 ID、参考/重构位置可通过悬停或可访问说明读取。缺失应力与零值严格区分；过期提醒同步到探针，新计算失败恢复旧快照与选择。
- 结果表的最小高度随阅读密度保留完整首行；短图区域省去与上下文栏重复的场标题、减少刻度，保留轴与单位。分区变化后延迟一次重排绘图，关闭后停止回调。
- 输入表格使用矩形单元格多选，增改仍保留字段表单入口；多行选中不允许“更新选中”误覆盖一行。复制/粘贴按可见列顺序使用原始值，隐藏字段不因粘贴被清空；“全部字段”可显式展开测点权重与积分字段，不自动选定积分区间。
- 粘贴、单值填充、向下填充和批量删除必须先校验候选表格、再一次提交；无效输入、非矩形数据、尺寸不符或超出列范围时整次拒绝，不修改选区、剪贴板和已提交模型。错误通过持续状态说明呈现，不弹模态窗口；单行表单错误保留原输入并定位对应字段。
- 三张输入表共用至多 100 次撤销历史，每次用户操作一个事务；表格快捷键限定表格焦点，文本框继续使用系统文字编辑快捷键。共享撤销必须检查目标表的可编辑状态，不能通过另一张表绕过计算中/插件恢复的限制；跨表撤销在当前页说明目标表。
- 批量编辑错误使用主题危险色与明确文字共同呈现，布局和中文换行完成后再滚动至反馈；最小窗口内完整可见且不改变选区。标准字号精简列无多余横向滚动，全部字段或大字号按可读列宽允许横向滚动，不裁掉不可见字段。“全部字段”置于上方记录信息行，避免挤压批量操作按钮。
- 新增行立即获得稳定实体 ID，粘贴不复制 ID；删除后保存再撤销也应恢复原 ID、名称与通道信息。项目载入、JSON/示例替换、接受建模器修改和节点几何变化时清除旧表格历史；保存不清历史，建模撤销不与表格撤销混用。
- 专注模式只隐藏输入区和结果表格，退出后恢复原有可见状态，不改变模型、结果或分割器比例。
- 工作台动画只用于必要的状态过渡，计算过程不使用持续装饰动画，以保证实时显示性能。启动页的方法演示允许循环，但必须可暂停、遵循减少动态偏好，并在离开后停止。
- 测点位置、贴片和测量轴只在输入与建模环境显示；结果视图专注结构形状和场数据。
- 空间曲线对话框使用类型选择器与分页面板区分三点圆弧、参数方程和 NURBS，不能把三类
  高密度字段堆入同一表单。参数方程页按“模板、定义域、三轴表达式、常量、预览”组织；
  输入变化经短延迟刷新轻量预览，错误必须定位到具体表达式、定义域或常量表，并支持键盘修正。

## 6. 后续扩展原则

- 新算法参数面板复用现有表单令牌，不新增算法专属主题色。
- 实时监测使用同一工作台结构，在结果区增加时间轴、质量状态和告警层，不重新堆叠页面。
- 三维曲梁、壳和实体结果继续由 VTK 视口承载，Qt 负责工具、属性和状态，不重复绘制三维场。
- 嵌入式 PyVistaQt 视口关闭默认后台自动渲染，由 Qt 主线程按数据变化主动刷新；父窗口退出前必须停止定时器、断开渲染信号并显式关闭 VTK 交互器。
- 每次界面迭代至少检查标准尺寸、最小尺寸、键盘焦点、长中文标签和无三维后端降级状态。
- 算法公式、领域模型和数据协议的变化必须与纯视觉调整分开评审和测试。

## 7. 应用外壳规范

- 程序启动时先显示功能型启动中心，不使用只能等待的计时闪屏；主窗口仅在用户选择新建、打开、示例或空白工作台后创建。
- 启动中心只提供真实可用入口，不伪造最近项目；最近项目列表必须等待全局项目历史持久化完成后再增加。
- 启动中心复用工作台的白色表面、当前主题主操作和橙红测点语义，代码绘制的结构示意不得引入 VTK 或 Matplotlib 启动成本。
- 启动页采用开放式左右构图：左侧两行主标题与新建/打开入口，右侧大幅空间网格梁；示例、空白工作台和退出使用安静的次级操作。保留 iFEM 品牌，统一石墨主题，不增加装饰卡片、说明箭头或非功能性指标。
- 启动主视觉由 `start_animation.py` 的原生 `QPainter` 矢量组件绘制，不读取图片资源，不调用求解器。陶橙表示应变观测，银灰网格表示重构形态，虚线表示参考构形；模型不再复用按钮主色。必须标明变形放大、仅为方法示意，不暗示当前支持三维或大变形求解。旧 SVG 和栅格资源仅作历史素材保留。
- 动态使用约 12 秒的观测、重构、停留和复位循环，最高约 30 帧/秒；暂停偏好仅写入本机 `QSettings`，不进入项目。隐藏、关闭、销毁、应用失活或项目库模态选择期间停止计时；恢复播放不补跑隐藏时间。macOS 减少动态偏好或 `IFEM_REDUCED_MOTION=1` 启用时固定展示完整形态，控制区显示“已减少动态”。
- 本次构图采用 Taste 的启动页专用尺度：`DESIGN_VARIANCE=5`、`MOTION_INTENSITY=4`、`VISUAL_DENSITY=3`，并按 UI/UX 的键盘、暂停和减少动态要求验收。重点是更轻的标题、低饱和表面、居中且舒展的梁形和减少阴影。这些低密度尺度不套用到数据密集的工作台或属性表；单主题明确优先于 skill 的双模式默认。
- 顶部工具区按意图分组：载入与数据交换属于次级命令，交互建模属于重要次操作，运行计算是页面唯一实心主操作。
- 建模器中的“保存项目”只写入项目库并保持窗口打开；“应用到工作台”只把当前
  模型交回分析工作台；会替换既有几何的生成动作必须明确写为“替换当前路径”。
- 建模器退出按实际模型内容与进入时基线比较，忽略纯 revision 变化，同时检查属性草稿；存在未应用修改时，关闭、取消和选择模式 Esc 共用确认，默认取消退出。取消确认不能关闭三维视口；保存过的文件不受放弃退出影响。
- 属性草稿按对象类型与稳定 ID 保留原始输入，只覆盖真正编辑过的字段；其他字段跟随模型、画布操作和撤销更新。截面/材料是独立草稿，切换截面类型可找回本次会话中该类型的未完成尺寸输入。重填表单时不得触发假修改。
- 属性栏提供“待应用”数量、草稿定位、当前表单还原及单项/全部放弃。单项还原不改变模型，批量放弃默认取消并说明草稿本身不在模型撤销栈内；已删除对象的草稿保留到显式放弃，撤销删除后可继续编辑，不允许把孤立草稿标成已保存。
- 保存或应用到工作台时先统一校验全部草稿，全部通过后才单次提交至模型撤销栈；失败不得半写入，错误边框、持久中文说明、焦点和滚动位置共同定位问题。测点表单优先呈现定位/方向/数据，快速布置操作置后。最小尺寸下组合框及属性栈不得因隐藏页面的最小宽度裁切输入。
- 打开另一个项目先校验目标文件，存在未应用内容时提供保存/放弃/取消。取消、损坏文件和保存失败不得切换项目或清除撤销历史；确认保存后重读目标，避免同路径打开使用旧快照。成功切换才清除旧草稿，不把打开文件误当作应用到工作台。
- 草稿限当前建模会话，不写入 v7 项目、不提供跨重启恢复；保存写盘失败或取消命名时，已通过校验的输入可保留为可撤销的模型修改，但不得显示“已保存”。
- “已保存”按实际保存内容核对，不能仅凭 revision 相等判断；撤销后分叉编辑可能复用 revision，但不得误标为已保存。截面尺寸草稿绑定原截面类型，跨类型撤销后不能把直径解释成高度。
- 测点应变以空白/“未录入”表示缺测，明确输入 `0` 才表示真实零应变；修改名称或布置属性不得把缺测自动补成零值。
- 工作区标题通过步骤提示、字号和字重建立层级；保持 UI-014 的常驻导航与白色检查器，不重新加入已移除的装饰线或重复标题。
- 分析摘要只轻量强调用户选择的重构方法，其余模型、测点和材料指标保持同一阅读层级。
- 结果工具栏只负责切换；当前空间、物理场、连续化方式和材料参数放入独立上下文条，不能覆盖二维图或三维视口。
- “测点残差”并列观测/重构/有符号差值，统一 με，摘要提供非加权 RMS 和最大绝对值；明确原始点值拟合残差不是真实误差，不凭颜色或无依据阈值判断合格。显示六位有效数字避免浮点尾数干扰，原值保留在通用字段表和快照。
- 通用字段表先呈现实体标签和物理分量，再给参考位置与来源；完整 ID、原值和重构位置可悬停查看，复制包含完整身份和原始精度。长表使用按需绘制，不用抽样冒充全部结果；字段缺位置显示缺失，不假定零坐标。
- 通用结果视图使用同一石墨令牌，工具仅含字段、分量与视角；三维使用真实 XYZ，二维明确标记 XY/XZ/YZ 投影。节点连线注明并非曲梁精确几何，变形不放大；只绘制有位置的离散字段点，不把未知插值呈现为连续云图。
- 通用插件的状态表并列参考 xyz、位移 ux/uy/uz 和原始转动表示；无字段时仍可检查状态。表格鼠标/键盘与图中节点/字段点按 ID 双向定位，改变投影保留选择；不提供当前字段时禁用对应应变/应力快捷入口，隐藏不适用的二维连续化与截面比例设置。
- 标准状态/离散点当前使用 Matplotlib 三维交互作为通用底层显示，已有 ASP-iFEM 的连续截面场仍使用原绘图器和 VTK；这不替代未来曲梁/壳/实体的 VTK 通用连续场。
- 后台任务显示真实阶段进度、短说明和明确“取消计算”按钮，不使用启动演示模拟进度。取消后说明等待当前步骤结束；锁定求解输入和项目变更，但保留旧结果查看。失败、取消、过期快照均不能清空有效旧结果。
- 关闭/应用退出时先确认取消任务并等待实际结束，再询问未保存输入；重复关闭选择“不关闭”可撤销待关闭状态，不能因迟到回调意外退出。结果更新和 VTK 渲染只在主线程执行。
- 状态栏左侧显示即时操作结果，右侧保留单位制、计算位置、数据连接和后台任务等持久状态。
- 项目库支持 `Ctrl+F` 搜索；Esc 在有搜索词时先清除筛选。空库、无匹配和损坏项目
  必须给出不同且可恢复的说明，错误原因不能只藏在鼠标悬停中。
- Qt 原生图标只有在目标平台风格统一时才使用；若不同平台出现彩色、拟物或年代感不一致的资源，优先保留清晰文字按钮。
